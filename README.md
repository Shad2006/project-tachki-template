# Project-Tachki-3ispr
Фамилия имя студентов, выполняющих задание: Хошвагт Шад

Стартовый репозиторий для проекта "АрендаТачек.рф". Выполняется на HTML, SASS, PHP и JavaScript.
Проект выполняется в группе из двух (максимум - трёх, при нехватке рабочих мест) человек.
Итоговый проект включает в себя: лендинг страницу, базу данных, генерируемые PHP-страницы, обработку почты, админ-панель.

💻Работа выполняется во время учебной практики **УП.09**.

🗃️Разработка ведётся в **отдельной ветке dev**. Слияние с основной веткой main только если начатая работа выполнена до конца и ошибки исправлены (например доделан до конца один из блоков и т.д., нет предупреждений от PHP или JS в консоли).
